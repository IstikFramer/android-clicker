# SPACE DIE

Работайте в существующем checkout. Сначала проверьте `git status`, инструкции и журнал этапа. Сохраняйте изменения пользователя. Переход к следующему из восьми этапов требует отдельного задания.

- Godot 4.7.2 stable standard, single precision, GL Compatibility и Jolt. Никакого GDNative, второго физического движка или экспериментальных потоков gdext. Все обращения к Godot и сигналы происходят на главном потоке.
- Rust stable закреплён внутри `rust/`. Весь Rust-код живёт в одном workspace. Команды Cargo запускаются из этой директории, обновление Cargo.lock должно быть осознанным. Проверки и CI используют `--locked`.
- Геометрия, повреждения, импульсы, гравитация и детерминированные вычисления принадлежат pure Rust. GDScript отвечает за оркестрацию, UI, камеру, VFX и жизненный цикл. Каждый разрушаемый объект работает в собственной локальной системе координат.
- Сохраняйте схему событий и типов из docs/contracts.md. Публикуйте отчёт один раз, проверяйте generation token после отложенных действий. Камерой управляет CameraDirector.
- UI по умолчанию русский, строки добавляются одновременно для ru/en в CSV. После импорта включайте актуальные файлы переводов. Комментарии в коде на английском.
- Новые сцены должны запускаться и решать задачу текущего этапа. Внешние ассеты требуют проверяемых источников и условий использования. Игра работает офлайн. Измеряйте производительность на указанном железе до заявления о FPS.
- Linux и Windows native собираются на соответствующих ОС. Коммитьте исходники и Cargo.lock. Артефакты сборки исключены через .gitignore.

## Проверки

```bash
tools/setup_linux.sh
export PATH="$PWD/.tools/bin:${CARGO_HOME:-$HOME/.cargo}/bin:$PATH"
(cd rust && cargo fmt --all -- --check && cargo check --locked --workspace --all-targets && cargo clippy --locked --workspace --all-targets -- -D warnings && cargo test --locked --workspace && cargo build --locked --workspace)
tools/build_native.sh debug
tools/smoke_linux.sh
```

На Windows используйте команды README. Для каждого изменения фиксируйте реально выполненные проверки и ограничения. Релиз публикуется отдельно от CI.
