# MangaLive

MangaLive — статический, но интерактивный прототип manga/webtoon-платформы в тёмной neo-editorial эстетике: графит, лайм, «бумажная» фактура и живые микровзаимодействия.

## Запуск

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Открой `http://localhost:4173` или live preview Arena.

## Что уже работает

- RU/EN переключатель интерфейса.
- Быстрый поиск по названию, автору и жанру.
- Фильтр жанров, сортировка, grid/list режимы.
- Избранное с сохранением в `localStorage`.
- «Моя полка» с состоянием empty state.
- Demo-reader: главы/страницы, прогресс, клавиши ← →, сохранение тайтла.
- Demo auth modal и toast-сообщения.
- Адаптивная версия для телефона и мобильное меню.
- Оригинальные сгенерированные artwork, hero-фон и кастомные chroma-key иконки; зелёный фон иконок обработан в прозрачные PNG для UI.

Проект сделан как самостоятельное направление MangaLive, вдохновлённое discovery/catalog-паттернами современных manga/webtoon-сервисов, без копирования чужого брендинга 1:1.
