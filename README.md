# Shell v0.1.4

Shell — расширяемая desktop-оболочка на Python и PySide6 в тёмном Fluent-стиле.
На Windows 11 приложение использует Mica, на Windows 10 — Acrylic, а на других
системах безопасно переходит к стеклянной QSS-стилизации без нативного blur.

## Запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

Для Windows устанавливаются нативные зависимости `pywin32` и
`PySideSix-Frameless-Window`. На Linux и macOS `pywin32` не требуется благодаря
условию платформы в `requirements.txt`.

Конфигурация пользователя хранится в `data/config.json`. Параметры эффекта
окна и прозрачности панелей применяются сразу после изменения. Журнал работы
записывается с ротацией в `data/app.log`.

## Структура

- `main.py` — точка входа.
- `core/` — окно, страницы, Fluent-адаптер, тема и инфраструктура.
- `plugins/` — каталог модулей. Сейчас доступен `file_manager`.
- `plugins/file_manager/` — сортировка, дубликаты, массовое переименование, анализ диска и поиск.
- `assets/icons/` — векторные ресурсы интерфейса.
- `data/` — пользовательская конфигурация и журнал работы.

## Плагины

Плагин добавляется как подпапка с `__init__.py` в `plugins/`. В модуле должны
быть `PLUGIN_INFO` и класс виджета, унаследованный от `QWidget`:

```python
PLUGIN_INFO = {
    "name": "Название модуля",
    "version": "0.1.0",
    "description": "Краткое описание",
    "author": "Разработчик",
    "icon": "folder.svg",
    "widget_class": "ModuleWidget",
}
```

Ошибки отдельных модулей изолируются загрузчиком и не останавливают оболочку.
