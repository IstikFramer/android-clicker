# Shell

Shell — стартовая оболочка для расширяемого desktop-приложения на Python и PySide6.

## Запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

Конфигурация пользователя хранится в `data/config.json`. Плагины добавляются как
подпапки с `__init__.py` в каталоге `plugins/`.

## Структура

- `main.py` — точка входа.
- `core/` — приложение, окна, страницы, тема и инфраструктура.
- `plugins/` — каталог будущих модулей.
- `assets/icons/` — векторные ресурсы интерфейса.
- `data/` — пользовательская конфигурация и журнал работы.
