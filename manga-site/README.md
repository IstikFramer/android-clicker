# MangaHub — сайт-каталог манги, манхвы, маньхуа и комиксов

Многостраничный сайт в духе MangaLib: тёмная тема, каталог с фильтрами, страницы тайтлов,
читалка глав, топ, жанры, команды перевода, закладки и история чтения.

Собран как **статический сайт без сборки и зависимостей** — чистый HTML + CSS + JS.
Данные лежат в одном файле `assets/js/data.js`, поэтому контент легко заменить на ответ API.

> **Важно:** реальной манги здесь пока нет. Все 70 тайтлов, ~5600 глав, обложки и страницы
> глав — сгенерированные заглушки (см. «Как добавить настоящую мангу» ниже).

---

## Запуск

```bash
cd manga-site
python3 -m http.server 8000        # или: npx serve, nginx — любой статический сервер
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом не стоит: браузеры режут загрузку скриптов
с `file://`, нужен любой HTTP-сервер.

## Страницы

| Файл            | Адрес                        | Что на странице                                                              |
| --------------- | ---------------------------- | ---------------------------------------------------------------------------- |
| `index.html`    | `#/`                         | Слайдер, «Последние обновления», «Сейчас читают», новинки, жанры, топ        |
| `catalog.html`  | `#/catalog`                  | Фильтры (тип, статус, страна, возраст, годы, жанры), сортировка, пагинация   |
| `manga.html`    | `#/manga/<slug>`             | Описание, список глав, отзывы, комментарии, оценка, похожие тайтлы           |
| `reader.html`   | `#/manga/<slug>/read/<глава>`| Читалка: лента / постранично, ширина, прогресс, выбор главы                  |
| `top.html`      | `#/top`                      | Подиум топ-3 и полный рейтинг, вкладки по типам и статусам                   |
| `genres.html`   | `#/genres`                   | Плитки жанров со счётчиками                                                  |
| `teams.html`    | `#/teams`                    | Команды перевода и их тайтлы                                                 |
| `favorites.html`| `#/favorites`                | Закладки и «Продолжить чтение»                                               |
| `login.html`    | `#/login`                    | Вход и регистрация (локально, без бэкенда)                                   |
| `about.html`    | `#/about`                    | О проекте, как запустить, как добавить контент                               |
| `feedback.html` | `#/feedback`                 | Форма обратной связи (демо)                                                  |

Маршрутизация — по hash (`#/…`), поэтому работает на любом статическом хостинге
и любая страница открывается напрямую по URL.

## Структура

```
manga-site/
├── *.html                     # страницы (общий шаблон, отличается только <title>)
├── assets/
│   ├── css/style.css          # все стили, CSS-переменные, светлая/тёмная тема
│   └── js/
│       ├── data.js            # СГЕНЕРИРОВАННО: демо-база тайтлов и глав
│       ├── core.js            # утилиты, роутер, localStorage, карточки
│       ├── covers.js          # генератор SVG-обложек и страниц-заглушек
│       ├── app.js             # шапка, футер, диспетчер страниц
│       └── pages/*.js         # рендеры отдельных страниц
└── tools/
    ├── generate_data.py       # генератор демо-базы
    └── e2e.js                 # автопрогон сайта (jsdom)
```

## Что сохраняется в браузере

Закладки, оценки, история и прогресс чтения, настройки читалки, тема и «аккаунт»
лежат в `localStorage` (ключи с префиксом `ml_`). Сервера нет — ничего никуда не уходит.

## Как добавить настоящую мангу

1. Откройте `tools/generate_data.py` и допишите тайтл в список `SEEDS`
   (slug, название, альт. название, тип, год, статус, возраст, рейтинг, просмотры,
   закладки, подписчики, жанры, описание), затем выполните `npm run data`
   (или `python3 tools/generate_data.py`).
2. Главы генерируются автоматически. Чтобы подставить реальные, формируйте
   `window.MANGA_DB` на своей стороне — структура описана в `assets/js/data.js`.
3. Обложки: сейчас их рисует `assets/js/covers.js`. Как только появится поле
   `cover` с URL картинки, замените `ML.Cover.uri(...)` на этот URL —
   остальной код менять не нужно.
4. Страницы глав: в `reader.js` вызывается `ML.Cover.pageUri(...)`.
   Подставьте реальные URL изображений — и читалка будет показывать сканы.

## Тесты

```bash
cd manga-site
npm install     # ставит jsdom (нужен только для тестов)
npm test
```

`tools/e2e.js` поднимает локальный статический сервер, грузит **настоящие** HTML-страницы,
исполняет **настоящие** скрипты сайта и кликает по настоящим элементам: фильтры каталога,
вкладки тайтла, поиск по главам, закладки, оценки, режимы читалки, вход, история,
404-страница и смена маршрута. 77 проверок.
