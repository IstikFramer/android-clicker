# Материалы и инструменты

Звёздный фон, кольца, газовая поверхность меню и материал демонстрационной сферы вычисляются шейдерами проекта. Сторонние модели, записи и текстуры в этапе 01 отсутствуют. UI выбирает установленный системный шрифт или использует встроенный шрифт Godot.

Godot 4.7.2 standard распространяется под MIT и содержит сторонние компоненты. Для дистрибутива с движком сохраните уведомления Godot и включённых библиотек. [Лицензии Godot](https://godotengine.org/license/)

Расширение использует godot-rust gdext 0.5.5. Зависимости и их версии записаны в Cargo.lock. Лицензия собственного проекта остаётся решением владельца. [godot-rust](https://github.com/godot-rust/gdext)
