# Контракты SPACE DIE

Все ID целей в нижнем регистре. Jupiter служит фоном и носителем ускорителя. Только активная цель имеет локальные физические координаты. Позиция измеряется в local units, длительность в sec, масса в game mass. Единичное направление безразмерно. Художественные величины не предназначены для прогноза реальных событий.

| weapon_id | target_id | power, целый процент |
| --- | --- | --- |
| railgun | mercury, venus, earth, mars, saturn | 10…100 |
| gungnir | mercury, venus, earth, mars, saturn | 100 |
| vera | те же цели и sun | 20…100 |

## Запрос и отчёт

ShotRequest наследует RefCounted. Поля включают уникальный за сеанс `shot_id: int`, `weapon_id: StringName`, `target_id: StringName`, `power: int`, конечный единичный `local_hit_dir: Vector3`, `country_id: String` и `seed: int`. Шаг мощности 1%. На Земле railgun требует код записи countries.json (обычно ISO alpha-2; при коллизиях и отсутствии ISO используется ADM0_A3 Natural Earth) или точную строку `Ocean`. На Земле для остальных оружий поле может быть пустым. На остальных целях требуется пустая строка. Невалидный запрос отклоняется. После fire вызывающая сторона рассматривает переданный запрос как неизменяемый.

ImpactReport наследует RefCounted. Идентификаторы и мощность соответствуют активному запросу. Поля `damage_fraction`, `integrity` и `atmosphere_fraction` — доли в [0,1]. `crater_radius_game_km` — художественный радиус в игровых км, ноль при неприменимости. `simulated_population_loss: int` ограничен диапазоном 0…population. `energy_index` — конечный неотрицательный игровой индекс. `destroyed: bool`, `status_key: StringName` и `activated_fragment_count: int` описывают исход и число активированных фрагментов. Статусы твёрдых тел — solid_impact / solid_destroyed, Сатурна — gas_impact / gas_dispersed, Солнца — solar_impact / supernova. После публикации отчёт неизменяем по соглашению.

## События и жизненный цикл

EventBus на главном потоке предоставляет следующие сигналы

```text
target_selected(target_id)          weapon_selected(weapon_id)
shot_started(request)               phase_changed(shot_id, phase, progress)
impact_committed(report)            news_event(shot_id, target_id, event_key)
shot_finished(shot_id)              world_reset(reset_id)
settings_changed()
```

Цепочка допустимых переходов проходит через MENU → LOADING → IDLE → TRAVEL → AIM → CHARGING → FIRING → IMPACT → AFTERMATH → IDLE. Вход в CHARGING требует принятого запроса из AIM. Commit требует совпадения поколения, состояния, полей активного выстрела и валидного отчёта. Повторный commit отклоняется. Выход из IMPACT требует commit. PAUSED сохраняет предыдущую фазу. Reset через RESETTING восстанавливает IDLE. Возврат в меню вызывает abort. Оба действия увеличивают generation и восстанавливают масштаб времени. Отложенные операции передают свой исходный token. Идентификаторы принятых выстрелов не переиспользуются в рамках сеанса.

## Нативный API

На этапе 01 единственная опубликованная операция — `FractureBridge.get_api_version() -> int`, результат 1. В тестах экземпляр создаётся через ClassDB. Контракт этапа 03 предусматривает

```text
plan_impact(fragments: Array[Dictionary], params: Dictionary) -> Dictionary
gravity_step(positions: PackedVector3Array, masses: PackedFloat32Array, params: Dictionary) -> PackedVector3Array
```

Планирование не меняет сцену. Результат gravity_step — ускорения в local units/sec². Схемы словарей и единицы закреплены в разделе этапа 03. На границе gdext ошибки данных обрабатываются без panic.


## Атлас и прицел этапа 02

PlanetDefinition хранит id, name_key, type, visual_radius в единицах сцены, reference_radius_km, условный distance_game_km, population (int64), probes, ключ атмосферы, карты, tint/accent, rotation_rate в рад/с, fracture_count, damage_resistance и news_channel. У Юпитера и Солнца сопротивление −1 обозначает неприменимость, news_channel пуст. У газовых тел и звезды fracture_count равен нулю.

В сценарии Меркурия работают 12 учёных, на Венере находятся восемь зондов и нет людей. Для Земли принято 8 000 000 000 жителей, для Марса — 120 000 колонистов, для станций Сатурна — 2 400 сотрудников. Население Солнца и Юпитера равно нулю. Эти значения предназначены для игровой статистики.

Нулевой меридиан направлен по +X, восточная долгота 90° по +Z, север по +Y. Геометрия печётся вокруг центра. Для сферы нормируем локальную вершину и вычисляем UV в шейдере, независимо от развёртки SphereMesh. Долгота равна atan2(z,x), широта равна asin(y). Горизонтальная координата равна fract(lon/TAU+0.5), вертикальная — 0.5-lat/PI. У полюсов долгота условна. Ограничение вертикального индекса последней строкой защищает южный полюс.

FractureBridge v1 дополнен тремя методами исследования поверхности. globe_uv(local_direction) возвращает Vector2 либо (-1,-1) для неверного направления. globe_direction(uv) возвращает единичный Vector3. pick_globe(origin, ray, radius) принимает локальные scene units, выбирает ближайший положительный корень и возвращает нормализованное направление. Нулевой вектор означает промах или неверный ввод. Hit пересчитывается в мировую точку через SpinPivot.to_global(local_hit_dir * visual_radius) в момент использования. Нажатие «Зафиксировать» сохраняет ShotRequest с полной тестовой мощностью и уникальным ID сеанса.

ID маски — R + 256×G. Код 0 соответствует Ocean. ID суши получается из трёх букв ADM0_A3 как 1+676a+26b+c при A=0. Географический поиск читает CPU Image без sRGB, mipmaps и интерполяции. AimArea использует бит 2, для будущих осколков зарезервирован физический слой 3. Оболочки, станции и декорации коллизий не имеют.

| Материал | Входы и пространство |
| --- | --- |
| planet_surface | day_map, normal_map, has_normal, tint, roughness, geology; локальная нормаль и освещение DirectionalLight3D |
| earth_surface | day_map, night_map (цвет), ocean_mask, damage_mask (линейные), damage_strength, sun_dir_local |
| clouds | cloud_map.a, density, cover, tint, sun_dir_local, u_time, damage_mask, damage_strength |
| atmosphere | tint, sun_dir_local; Fresnel и освещённый край |
| gas_giant | tint, belt, storm, u_time; широтные полосы, локальное пятно |
| saturn_rings | tint; UV.x от внутреннего до внешнего радиуса, UV.y вдоль кольца |
| sun_surface, solar_corona | u_time в секундах сцены; эмиссия и край короны |
| stars | направление EYEDIR; разреженные звёзды и пылевая полоса |

sun_dir_local направлен от центра к источнику света. Для каждого экземпляра используется обратный базис его SpinPivot и ось +Z локального DirectionalLight3D. damage_strength по умолчанию равна нулю. Повреждение подготовлено как вход материала для следующих этапов.

## Разрушение в этапе 03

В файлах `data/fractures/<planet_id>.json` значение `version` равно 1. Для Меркурия, Венеры, Земли и Марса запечено соответственно 240, 300, 480 и 280 ячеек. Исходная сетка имеет 48 меридианов и 24 широтных интервала, нормализованный радиус 1, объём 4,1589714. Поля `seed`, `source_mesh_hash` и `source_volume` идентифицируют вход. SHA256 алгоритма и каждого файла находятся в соседнем manifest.json. CLI пересекает выпуклый объём с биссекторными полупространствами в f64. Набор точек создаёт ChaCha8. При вырожденной ячейке допускаются ещё три детерминированные попытки для того же входного seed.

В каждой ячейке хранятся `id`, нормализованный `centroid`, `volume`, `max_radius`, `bounds`, `outer_area`, `layer`, `neighbor_ids`, координаты `vertices_flat` относительно центроида, `collision_points` и два массива индексов. Обход внешних и внутренних граней в файле против часовой стрелки при взгляде снаружи. Загрузчик меняет порядок для Godot и масштабирует локальные точки на `visual_radius`. Внешний слой получает радиальные нормали и UV по исходному направлению, треугольники на шве развёрнуты в соседний период. Внутренние грани имеют плоские нормали, объёмный шум привязан к исходным координатам. При подготовке демо целая поверхность собирается из этих же внешних треугольников.

`FractureBridge.plan_impact` принимает типизированный `Array[Dictionary]`. ID образуют непрерывный диапазон от нуля. Каждая строка содержит целые `id`, `neighbor_ids: PackedInt32Array`, нормализованные по радиусу координаты `centroid: Vector3`, положительный `volume: float`, необязательную `outer_area: float` и флаг `active: bool` уже отделённой части. Для типов gas и star массив пуст. Словарь параметров содержит следующие поля.

| Поля | Значение |
| --- | --- |
| weapon_id, target_type, power | String или StringName, тип rocky/gas/star и целый процент. Railgun 10–100, Gungnir 100, VERA 20–100. Для звезды принимается VERA. |
| local_hit_dir, seed | Конечный единичный Vector3 в системе SpinPivot и int64. |
| resistance, scene_radius | Игровой коэффициент твёрдости и радиус в единицах сцены. |
| prior_integrity, atmosphere_fraction | Оставшиеся доли исходной массы и атмосферы от 0 до 1. Для твёрдой цели масса обязана совпадать с состоянием ячеек. |
| remaining_population | Оставшееся сценарное население, неотрицательный int64. |

Ошибка возвращает `ok=false` и строку `error`. При успехе позиции в `selected_ids`, `masses`, `impulses`, `angular_impulses` соответствуют друг другу. Масса игровая, импульс равен массе, умноженной на изменение скорости в локальных единицах сцены в секунду. `damage_fraction` показывает отделённую долю первоначальной массы. `integrity`, `atmosphere_fraction` и `simulated_population_loss` используются для следующего удара. `crater_radius_game_km` вычисляется по суммарной площади внешних граней отделённых ячеек и равен нулю для газа, звезды и полного разрушения. `energy_index` — художественный индекс. `status_key` и `destroyed` переносятся в ImpactReport. Параметры `heat_seconds`, `wave_intensity`, `ejecta_speed`, `emissivity`, `breakup_seconds` и `annihilate` управляют общей последовательностью эффектов.

В момент удара вращение цели фиксируется. Оставшаяся оболочка требует до двух поверхностей ArrayMesh. Внешние и доступные внутренние грани получают свои материалы. Каждый выбранный ID получает собственную геометрию. По значимости для камеры отбираются 48/96/160/500 физических тел. Остальные видимые части перемещаются баллистически под общим узлом. Через запланированный интервал распада тело получает единственный линейный и угловой импульс на физическом такте. До 24 тел получают взаимные контакты через 0,23 с. Коллайдеры уменьшены до 98,2%. Обычные тела возвращаются в пул через 8–18 с. Аннигиляция VERA сокращает этот интервал и масштабирует осколки до исчезновения.

`gravity_step` принимает до 96 позиций, столько же положительных масс и параметры `g_game`, `epsilon`, `max_acceleration`. Результат содержит ускорения в том же порядке. При неверных параметрах возвращается пустой PackedVector3Array. Пул обновляет парные ускорения примерно 12 раз в секунду и прикладывает силу m·a на физических тактах.

Газовая цель сообщает gas_impact или gas_dispersed, деформирует полосы и кольца, а при Gungnir выбрасывает струю с дальней стороны. Солнце возвращает solar_impact и отчёт о целостности. Сверхновая относится к этапу 06. В этом этапе удар запускает демонстрационный сценарий. Обычное подтверждение прицела в атласе сохраняет ShotRequest.

## RAILGUN этапа 04

В `SpaceWorld` пользователь выбирает локальную точку и целую мощность 10–100. На Земле `country_id` хранит код региона, включая Ocean. Платформа предоставляет `get_valid_targets()`, `can_fire(request)` и сокеты CameraAnchor, WarpOrigin, Muzzle. Оркестратор `RailSequence` реализует `begin_travel(id)`, `start_sequence(request, generation)`, `skip()` и `cancel_sequence()`. Единственная Camera3D следует за установкой. Поворот орбиты меняет позу установки, цель и активные обломки остаются в своих координатах.

ShotDirector копирует запрос при FIRE и владеет поколением, активным выстрелом и единственной публикацией ImpactReport. При завершении полёта RailSequence ставит действие в очередь физического тика. FractureController использует существующий Rust-план для изменения сцены и передаёт его численные результаты в ShotDirector.commit. Отчёт получает UI. События discovered, charge_started, phase_changed, fired, impact_committed, aftershock, signal_lost и news_event идут через EventBus. Задержка баса задаёт художественный ритм. Переключения цели сохраняют ID отделившихся ячеек, состояние атмосферы, населения, отметок и вращения в GameState.damage_history. Восстановление выбранной цели удаляет её запись.

SequenceClock читает монотонное время, останавливает шкалу при паузе и потере фокуса, обновляет точку отсчёта при возврате. На ударе физика замедляется до значения slow_scale на 0,60–0,86 с. Затем скорость возвращается к единице за 0,47 с. Профили представления интерполируются по семи ключам balance.json. Рельеф, визуальная симуляция облаков, тряска и условные индексы этой сцены служат игровому изображению.
