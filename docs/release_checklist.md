# Пробная упаковка Windows x64

Workflow Windows demo package собирает Windows x64 с MSVC и проверяет ZIP. Ручной запуск сохраняет артефакт задания. Теги демо, перечисленные в release.yml, публикуют проверенный архив в GitHub Releases.

1. Установить Rustup и Visual Studio Build Tools с C++ workload. Выполнить `./tools/setup_windows.ps1 -Templates`.
2. Выполнить `./tools/export_windows.ps1`. Скрипт проверяет debug-сборку и smoke, собирает release DLL с `+crt-static` и экспортирует в отдельный каталог внутри dist.
3. Выполнить `./tools/package_windows.ps1`. Скрипт проверяет наличие EXE, PCK и DLL, исследует PE imports через dumpbin и блокирует непроверенную зависимость от VC redistributable. При появлении такой зависимости проверить возможность статической линковки либо право на распространение подходящей app-local DLL.
4. Скрипт распаковывает итоговый ZIP во временный каталог и запускает headless smoke с тайм-аутом. Для финального допуска развернуть тот же ZIP на чистой Windows x64 без инструментов разработчика, без дополнительно установленного VC runtime и без сети. Запустить интерактивно, проверить обе локали, переход в мир, возврат, перезапуск и сохранение настроек.
5. Проверить уведомления и лицензии всех распространяемых компонентов, кредиты и результаты измерений на целевом GPU. Записать SHA256 принятого ZIP и протокол проверки.

SHA256 для Godot в setup получены из загруженных официальных архивов после сверки с SHA512-SUMS.txt того же релиза. Linux editor — cadd3204…329e4, Windows editor — 731980f9…1e953, шаблоны — f298490b…48011. Полные значения находятся в скриптах. [Официальный релиз Godot 4.7.2](https://github.com/godotengine/godot-builds/releases/tag/4.7.2-stable)
